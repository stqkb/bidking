## 四、出价策略参考

### 关键指标

| 指标 | 数值 |
|:---|---:|
| 全场总价值 / 红色藏品系统价格 | 平均 **1.36倍** |
| 全场总价值最低倍率 | 1.00倍（第16局） |
| 全场总价值最高倍率 | 3.42倍（第21局） |
| 盈利局成交价 / 全场总价值 | 平均 **0.84倍**（即以总价值84%拍得可盈利） |
| 亏损局成交价 / 全场总价值 | 平均 **1.65倍** |

### 按平均格数区间的出价建议

| 平均格数区间 | 特征 | 建议策略 |
|:---:|:---|:---|
| 1.0 - 1.5 | 全场总价值通常 40-80万，但波动大 | 出价 50-60万，注意第6局（1.0平均）总价值高达246万 |
| 1.7 - 2.0 | 最常见区间（8局），总价值 50-130万 | 出价 60-70万，避开极端竞价（第11局教训） |
| 2.2 - 2.5 | 总价值 40-116万 | 出价 40-50万，该区间盈利概率较高 |
| 2.8 - 3.4 | 总价值 90-112万 | 出价 85-100万，该区间全部盈利 |
| 3.7 - 4.0 | 总价值 40-193万，波动最大 | 出价需谨慎，参考最低出价 |
| 5.0 - 8.5 | 总价值 100-173万，大件藏品 | 出价 70-120万，该区间多数盈利 |
