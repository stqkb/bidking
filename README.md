# 竞拍之王（BidKing）

拍卖资产预估与视觉识别辅助工具：通过机器学习 + 视觉特征匹配，对游戏拍卖场中的拍品进行价值估算、格数识别与出价建议，并维护一套可持续学习迭代的红色品质物品图鉴。

## 项目简介

每场拍卖会有不同大小的拍品，其中红色品质价值最高。本项目基于历史对局数据 + 学习图片库：

- **识别**：通过 ResNet50 提取拍品截图特征，在已标注的学习图片库中匹配出对应藏品与格数；
- **估值**：结合权威价格表（Excel 导入）、31+ 局实测单价与 ML 背景概率模型，输出预计总价值与保守出价建议（基于 p10 下限 × 安全系数，规避"赢家诅咒"）；
- **学习**：每次导入新对局、新增/删除学习图片后，模型自动重训与更新索引，样本会持续积累。

## 功能特性

- 🖼️ **红色图鉴管理**：200+ 藏品、3000+ 学习图片，支持批量导入、逐张删除、变体标记、滚轮浏览
- 🔍 **视觉识别**：ResNet50 特征库（2048 维）余弦检索，支持小样本匹配策略
- 📊 **估值引擎**：ML 背景概率 + 规则引擎双通道，按格数分位（P10~P90）输出价值区间与推荐出价
- 📈 **对局分析**：局汇总、平均格数归类、历史单价融合
- 📷 **OCR 截图识别**：RapidOCR 自动读取拍卖结果截图并归档
- 🖥️ **高级 Web UI**：React + ECharts 可视化，无需重启即可热更新数据

## 技术栈

| 层 | 技术 |
|---|---|
| 后端 | Python 3.11 · FastAPI · Uvicorn |
| 机器学习 | PyTorch（ResNet50 特征提取）· scikit-learn · scipy |
| OCR | RapidOCR（ONNX Runtime） |
| 存储 | SQLite（`data/bidking.db`）+ JSON 索引（`crops_manifest.json`）+ 图片文件 |
| 数据处理 | pandas · openpyxl（Excel 价格表导入） |
| 前端 | React 18 · TypeScript · Vite · ECharts |

## 运行环境

- **操作系统**：Windows / macOS / Linux（本项目在 Windows 11 开发验证）
- **Python**：3.10+（建议 3.11，需含 fastapi、torch、torchvision 等依赖，见 `backend/requirements.txt`）
- **Node.js**：18+（仅前端开发/构建时需要；生产运行无需）
- **硬件**：CPU 可运行全部功能；有 NVIDIA GPU（如 RTX 4060）时 ResNet50 特征提取速度约翻倍
- **部署形态**：本地单机 Web 应用（后端托管前端静态资源，`http://127.0.0.1:8000`）

## 快速开始

### 1. 安装后端依赖

```bash
cd backend
pip install -r requirements.txt
```

### 2. 启动服务

```bash
python backend/run.py
```

浏览器自动打开 `http://127.0.0.1:8000`。首次启动会加载 ResNet50 模型并预热特征库（约 1 分钟）。

### 3. （可选）前端重新构建

仓库自带 `frontend/dist` 构建产物，改动前端源码后需重新构建：

```bash
cd frontend
npm install
npm run build
```

构建完成后刷新浏览器即可生效（后端无需重启）。

## 使用说明

1. **导入价格表**：在图鉴页上传红色品质物品汇总表（Excel），自动建立权威价格库与格数分位统计；
2. **学习图片**：从截图裁剪拍品图并标注藏品名/格数，存入图鉴作为视觉识别样本；可逐张删除与标记变体；
3. **每局预估**：输入红色拍品平均格数与单件具体信息，系统结合历史单价给出预计总价值与出价建议；
4. **自动学习**：导入新对局或增删样本后，估值引擎自动重训，无需手动操作。

## 数据说明

- 学习图片索引（`crops_manifest.json`）与磁盘图片一一对应；删除图片建议在 Web 界面操作以保持索引同步。
- 数据库、图片等运行数据随代码一同入库，克隆后即可开箱使用（含 200+ 藏品与 3000+ 学习图片）。
