# 竞拍之王（BidKing）— 全新 UI 设计方案

> 设计师：UI Designer
> 日期：2026-08-14
> 版本：v2.0 Design Spec
> 适用：React 18 + TypeScript + Tailwind CSS + ECharts

---

## 一、设计愿景与原则

### 1.1 设计定位

**"拍卖行级的高端数据工具"** — 融合苏富比拍卖行的沉稳质感与现代金融 Dashboard 的信息密度，让用户在每一次估值决策中感受到专业、精准与掌控感。

### 1.2 核心设计原则

| 原则 | 说明 | 落地策略 |
|------|------|----------|
| **信息分层** | 用户视线按"结论 → 数据 → 细节"递进 | 卡片内结论前置，展开折叠区域放细节 |
| **决策导向** | 每个页面有明确的"主行动点" | 出价建议、识别确认等核心 CTA 视觉优先级最高 |
| **渐进披露** | 复杂参数不一次性堆叠 | 高级参数折叠，常用参数默认展开 |
| **状态可感知** | 系统状态（训练中/离线/数据量）始终可见 | 顶栏状态条 + 页面内状态徽章 |
| **视觉一致性** | 所有组件遵循统一设计令牌 | 禁止硬编码颜色/间距，全部走 CSS 变量 |

### 1.3 与现有设计的改进对比

| 维度 | 现有 v1 | 新方案 v2 |
|------|---------|-----------|
| 导航 | 顶部 5 tab，无总览页 | 侧边栏 + 顶部面包屑，新增 Dashboard 总览 |
| 信息密度 | 单页堆叠大量表单 | 分步式工作流 + 折叠高级参数 |
| 色彩体系 | 暖金单色 + 旧类名兜底映射 | 三层语义色（金/翠/朱）+ 清理遗留映射 |
| 数据可视化 | 基础 ECharts | 统一图表风格 + 卡片化数据指标 |
| 响应式 | 仅 max-w-6xl 居中 | 侧边栏可折叠，适配 1280px~1920px |
| 空状态 | 无专门设计 | 每个页面有空状态引导插画/文案 |

## 二、设计系统（Design Tokens）

### 2.1 色彩系统

#### 基础色阶 — 墨黑系（Ink）

用于背景、卡片、边框，营造深沉的拍卖行氛围。

```css
:root {
  /* 背景层 — 由深到浅 */
  --ink-950: #0E0E12;    /* 全局背景：近乎纯黑，带微蓝调 */
  --ink-900: #16161C;    /* 卡片背景：主容器 */
  --ink-850: #1C1C24;    /* 次级卡片 / 弹出层 */
  --ink-800: #22222B;    /* 输入框 / 表格行 hover */
  --ink-700: #2E2E38;    /* 细边框 / 分割线 */
  --ink-600: #3A3A48;    /* 焦点边框 / 强调分割 */
  --ink-500: #545466;    /* 禁用态边框 */
}
```

#### 强调色 — 三色语义体系

```css
:root {
  /* 主强调 — 鎏金（核心行动、品牌识别） */
  --gold-300: #E8D4A0;   /* 浅金：hover 高亮 */
  --gold-400: #D4B978;   /* 标准金：按钮、链接 */
  --gold-500: #C9A962;   /* 品牌金：Logo、主 CTA */
  --gold-600: #B8964E;   /* 深金：active 按压 */
  --gold-soft: rgba(201, 169, 98, 0.12);  /* 金色透明底：badge、选中态 */

  /* 语义色 — 翠绿（成功、盈利、低风险） */
  --jade-400: #5BBA8A;
  --jade-500: #4A9A6A;
  --jade-soft: rgba(74, 154, 106, 0.12);

  /* 语义色 — 朱红（危险、亏损、高风险） */
  --vermilion-400: #E06B6B;
  --vermilion-500: #C44A4A;
  --vermilion-soft: rgba(196, 74, 74, 0.12);

  /* 语义色 — 琥珀（警告、中风险、训练中） */
  --amber-400: #E0B056;
  --amber-500: #C99A3E;
  --amber-soft: rgba(201, 154, 62, 0.12);
}
```

#### 文字色阶

```css
:root {
  --text-primary:   #ECE9E4;    /* 主文字：标题、正文 */
  --text-secondary: #A8A4A0;    /* 次要文字：描述、标签 */
  --text-tertiary:  #6E6B68;    /* 占位符、禁用文字 */
  --text-inverse:   #16161C;    /* 金色按钮上的深色文字 */
  --text-money:     #E8D4A0;    /* 金额数字：浅金，突出数值 */
}
```

#### 色彩使用规则

| 用途 | 色值 | 说明 |
|------|------|------|
| 主 CTA 按钮 | `--gold-500` 底 + `--text-inverse` 字 | 全页仅 1-2 个主 CTA |
| 次级按钮 | 透明底 + `--ink-600` 边框 + `--text-primary` 字 | |
| 危险操作 | `--vermilion-500` 底 + 白字 | 删除、重置等 |
| 成功状态 | `--jade-500` 图标/文字 | 盈利、训练完成 |
| 金额展示 | `--text-money`（浅金） | 所有价格数值统一 |
| 风险等级-低 | `--jade-500` | |
| 风险等级-中 | `--amber-500` | |
| 风险等级-高 | `--vermilion-500` | |

```css

  --text-sm:   14px / 22px;   /* 表格、描述 */
  --text-base: 16px / 26px;   /* 正文、输入框 */
  --text-lg:   18px / 28px;   /* 卡片标题 */
  --text-xl:   20px / 30px;   /* 区块标题 */
  --text-2xl:  24px / 34px;   /* 页面标题 */
  --text-3xl:  30px / 40px;   /* 数据指标 */
  --text-4xl:  36px / 44px;   /* 核心数值（出价建议） */

  /* 字重 */
  --fw-regular:  400;
  --fw-medium:   500;

  --fw-bold:     700;

```

**字体使用规则**：
- 标题：`--font-display` + `--fw-semibold`
- 正文：`--font-sans` + `--fw-regular`
- **所有金额/数值**：`--font-mono` + `tabular-nums`（等宽数字对齐）
- 金额前缀"￥"或"万"用 `--text-sm` + `--text-secondary`，数字本体用 `--text-money`

### 2.3 间距系统

基于 **4px 基准单位** 的 8 点网格：

```
--space-0:  0px      --space-1:  4px     --space-2:  8px
--space-3:  12px     --space-4:  16px    --space-5:  20px
--space-6:  24px     --space-8:  32px    --space-10: 40px
--space-12: 48px     --space-16: 64px    --space-20: 80px
```

| 场景 | 间距 |
|------|------|
| 组件内元素间距 | `--space-2` (8px) ~ `--space-3` (12px) |
| 卡片内 padding | `--space-5` (20px) ~ `--space-6` (24px) |
| 卡片间间距 | `--space-4` (16px) ~ `--space-6` (24px) |
| 区块间距 | `--space-8` (32px) ~ `--space-12` (48px) |
| 页面外边距 | `--space-6` (24px) ~ `--space-8` (32px) |
