# 竞拍之王 · 红品估值与出价助手

本地网页应用：手动输入每场对局信息（红品均格 + 已知单件红品，其他品质可选），系统反推红品格数组合、
估算红品与全场总价值，输出**估值区间 + 推荐出价 + 风险等级**；每场结算后录入真值，模型自动持续重训。

## 快速开始

双击 `启动.bat`（首次启动会自动导入 188 件图鉴与 31 局实战数据，并在后台训练表格 ML 与 CNN 模型）。
浏览器自动打开 `http://127.0.0.1:8000`。

依赖（本机已装）：Python 3.11 + fastapi/uvicorn/scikit-learn/scipy/joblib/openpyxl/pandas/numpy/torch(CPU)。
前端为构建产物（`frontend/dist`），运行时无需 Node。

## 功能

- **新对局估值**：输入红品均格与已知红品信息 → 枚举 (总格数, 件数) 候选与格数组合（如 `1+1+1+4+4`）→
  结合图鉴与 31 局实测单价估算红品/全场价值区间 → 给出推荐出价与风险。
- **持续学习**：历史复盘页录入结算真值后自动重训；模型面板展示留一交叉验证（MAE/MAPE/R²/区间覆盖率）、
  校准曲线与特征重要性。模型集成 = 贝叶斯岭 + 高斯过程 + 梯度提升的**残差回归**（以规则估值为先验）。
- **深度卷积（棋盘 CNN）**：在 16×16 棋盘摆放看到的红品形状，用 188 件图鉴合成的 4 万张布局预训练
  小 CNN，再以 31 局真实数据线性校准，结果可与规则引擎 50/50 融合。
- **图鉴管理**：导入/重导你的 Excel 红色图鉴，查看按格数的价值统计。

## 目录结构

```
竞拍之王项目/
├─ 对局数据/            # 你的原始数据（只读）
├─ backend/             # FastAPI + 规则引擎 + ML + CNN
│  ├─ app/engine.py     # 均格反推、格数组合 DP、价值聚合、出价建议
│  ├─ app/ml.py         # 残差回归集成与持续重训
│  ├─ app/cnn.py        # 合成布局 + PyTorch CNN + 真实校准
│  ├─ app/importers.py  # Excel / md 解析入库
│  └─ tests/            # pytest 单元测试
├─ frontend/            # React + TypeScript + Tailwind + ECharts（已构建到 dist）
├─ data/                # SQLite 数据库与模型文件（运行时生成）
├─ 启动.bat
└─ README.md
```

## 方法说明与局限

- 规则引擎的“经验单价”来自你的 31 局实测（每格数取均值），图鉴用于兜底与稀有高价品上限（蒙特卡洛区间）。
- 20–40 个样本下深度学习无法端到端训练，因此 CNN 采用**合成预训练 + 真实校准**，仅作辅助；主模型是规则 + 表格 ML。
- 全场总价值/红品价值的实测倍率约 1.36；盈利局成交价/总价值约 0.84，作为默认推荐出价 margin。
- 单场价值受“抽中稀有品”影响波动很大，区间会相应变宽；随结算记录增多，模型会逐步收敛。
